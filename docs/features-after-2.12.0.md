# Features and fixes after Chainlit 2.12.0

Inventory of `7c82f51f..HEAD`, where `7c82f51f` set
`__version__ = "2.12.0"`. It covers the `[3.0.0]` changelog plus post-bump
changes that have no changelog entry; it is not the fork's full history. The
prompt gallery and scheduled prompts from `7c82f51f` itself are out of scope.
Every path below was checked against the working tree.

## Run the demo

[backend/chainlit/sample/whats_new_after_2_12](../backend/chainlit/sample/whats_new_after_2_12/README.md)
has one app for these changes. Rebuild the frontend if `frontend/dist` predates
the interaction cards, then run from the demo directory:

```bash
pnpm --filter @chainlit-ng/react-client build
pnpm --filter @chainlit/app build

cd backend/chainlit/sample/whats_new_after_2_12
uv run chainlit run app.py -w
```

Open <http://localhost:8000> and sign in with `demo` / `demo`. The demo has no
data layer, so approvals and questions stay in memory; persistence and resume
paths are covered by the backend tests below.

## Known coverage gaps

Verified by searching the test tree; these are absent, not just unexercised by
the demo.

- **Thread grants have no client coverage.** `rg -n 'threadGrants|/grants' frontend/tests cypress` returns nothing, and `rg -n 'grants' frontend/src` finds no grant UI. Only backend tests cover the routes.
- **No Cypress spec for message timestamps.** `rg -n 'show_message_timestamps|timestamp' cypress` finds none; Vitest covers rendering.
- **No Cypress spec for element positions.** `rg -n 'elements_position|elementsPosition' cypress` finds none.
- **No Cypress spec for `cl.open_side_view`.** Only backend and Vitest tests exist.
- **No test for the login label or dependency floors.** `rg -n 'Username or email' backend/tests frontend/tests cypress` finds none, and no test pins `opentelemetry-api>=1.45.1` or the `custom-data` extras.
